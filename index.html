This is the developer-operated public beta feed. No account is required. It is separate from F-Droid’s default catalogue.

Guided on-device ADB setup needs no computer or separate Shizuku app. Keep Settings and the app visible in split screen while pairing. Computer ADB and Shizuku remain alternatives. Setup, source and limitations · APK releases · Feedback

No telemetry or uploads are included. Network permission is used only for temporary on-device ADB setup. Signed beta updates preserve local history; differently signed debug previews require uninstalling first, which removes saved history.
